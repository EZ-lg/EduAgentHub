## 一、P2 已完成内容

### 1.1 backend/ai/ 服务层（全新）

- **`base.py`** — `BaseLLMProvider` 抽象基类
  - 类级元信息：`name` / `label` / `supports_chat` / `supports_embedding` / `default_base_url` / `default_models` / `default_embedding_models`
  - 抽象方法：`chat(messages) -> str`、`chat_stream(messages) -> Generator`、`embed(texts) -> List[List[float]]`
  - 内置健康检查：`check_chat()` / `check_embed()` / `health_check(mode="chat"|"embed")`，返回 `{"ok": bool, "message": str, "latency_ms": int}`
  - `to_meta()` 类方法 → 前端设置页渲染下拉框用
- **`providers/`** — 5 个 Provider（比交接文档要求的 2 个多实现了 3 个）
  - `openai_provider.py` — OpenAI 官方，Chat + Embedding
  - `deepseek_provider.py` — 继承 OpenAIProvider，仅 Chat（`embed()` 抛 NotImplementedError）
  - `qwen_provider.py` — 通义千问（DashScope 兼容模式），Chat + Embedding
  - `claude_provider.py` — Anthropic SDK，仅 Chat（`_to_anthropic_messages()` 处理 system 提取 + 连续同角色合并）
  - `custom_openai_provider.py` — 自定义 OpenAI 兼容（Ollama/vLLM 等），Chat + Embedding
  - **关键**：deepseek/qwen/custom 都是 OpenAI 兼容协议，直接继承 OpenAIProvider，只在类属性上覆盖 name/label/supports_embedding/default_* 即可
- **`factory.py`** — `PROVIDER_CLASSES` 注册表 + `create_provider(config)` + `get_provider_meta()`
- **`manager.py`** — `AIManager` 单例（模块级 `ai_manager`）
  - 从 settings 表读 `llm_config` / `embedding_config`，自动创建/缓存 Provider
  - 配置签名比对：配置变了自动重建实例，无需手动刷新
  - `get_llm()` / `get_embedding()`（未配置返回 None）、`is_configured(kind)`、`reload_config()`
- **`prompts/`** — `prompt_loader.py`（Jinja2 渲染，`render_prompt(name, **kwargs)`）+ 9 个模板文件
  - 模板内容目前是占位注释，P4/P5/P6/P8 各阶段按需完善
  - `undefined=StrictUndefined`：模板里引用了未传入的变量会直接报错，防止 Prompt 静默缺字段

### 1.2 backend/routers/settings.py（重写）

- `GET /api/settings` — 返回所有设置，`value_json` 解析为 JSON 对象（不是字符串）
- `GET /api/settings/providers` — 返回 5 个 Provider 元信息（前端设置页下拉数据源）
- `PUT /api/settings` — 批量更新；dict/list 自动 `json.dumps` 存储；AI 配置变更后自动 `ai_manager.reload_config()`
- `POST /api/settings/test-llm` — body 传配置用传入配置测，否则用已保存配置
- `POST /api/settings/test-embed` — 同上
- 测试连接返回 `{"ok": false, "message": "真实错误信息", "latency_ms": 674}`，前端据此显示 ✅/❌

### 1.3 前端

- **`pages/settings.html`（重写）** — Tab 结构：AI配置 / 机构信息 / 数据管理 / 关于
  - AI配置 Tab：左右两栏 LLM 配置 + Embedding 配置
  - 表单：Provider 下拉、API Key（带显示/隐藏）、Base URL、模型名（datalist 候选）、温度滑块、最大 Token
  - 「测试连接」用当前表单配置（无需先保存）；「保存配置」写入 settings 表
  - Embedding 下拉只列出支持 Embedding 的 3 个 Provider（openai/qwen/custom_openai）
  - 切换 Provider 自动填充默认 Base URL + 模型候选
  - 其余 Tab 为占位（机构信息/数据管理留到后续阶段）
- **`js/app.js`（修复 P1 bug）** — 页面模板用 v-html 注入，浏览器**不会执行内联 `<script>`**，导致 P1 的学生列表/工作台 JS 全都没跑起来
  - 新增 `executeInlineScripts(container)`：手动重建 script 节点触发执行
  - `createPageComponent.mounted()` 里在 `await nextTick()` 后调用
  - **顺带修复了 student_list / dashboard / student_detail 页面的 JS 不生效问题**
  - 新增 `window.showToast = showToast`，供页面内联脚本调用
- **`js/api.js`** — settings 加 `providers()` 方法
- **`components/navbar.html`** — 版本号 `v1.0.0 · P1` → `v1.0.0 · P2`
- **`css/style.css`** — 新增 `.settings-tab` / `.settings-label` 样式

## 二、关键架构决策

| 决策 | 说明 |
|------|------|
| Provider 全部 5 个 | 交接文档要求最少 2 个，实际做了 5 个（deepseek/qwen/custom 复用 OpenAI 兼容协议，成本极低） |
| OpenAI 兼容协议复用 | DeepSeek/Qwen/自定义 都继承 `OpenAIProvider`，只覆盖类属性，无重复代码 |
| Embedding 模型名独立 | `embedding_model` 字段存在 embedding_config 里，与聊天模型分开 |
| 配置签名比对缓存 | AIManager 用 `json.dumps(config, sort_keys=True)` 做签名，配置一变自动重建 Provider |
| 测试连接不依赖已保存 | test-llm/test-embed 传当前表单配置，填好就能测，不用先保存 |
| 页面脚本手动执行 | v-html 不执行 `<script>`，通过重建 script 节点解决，这是 P1 遗留 bug 的修复 |
| 测试返回结构 | `{"ok": bool, "message": str, "latency_ms": int}` 嵌在 `data` 里，前端渲染绿色✅/红色❌ |
| 前端缓存破除 | `index.html` 里 JS/CSS 引用带 `?v=N`，改动前端后**递增版本号**，否则用户浏览器会缓存旧文件导致页面 JS 不生效（P2 已踩过这个坑） |

## 五、注意事项（给下一个 AI）

1. **不要动前端风格**：白色简洁风、侧边栏布局（4 主导航 + 底部系统设置）不要再改
2. **AI 调用统一走 `ai_manager` 单例**：`from backend.ai.manager import ai_manager`，`ai_manager.get_llm()` 返回 Provider，`get_llm()` 返回 None 表示未配置（前端先弹提示引导去设置页）
3. **设置页是 P3+ 的入口提示**：任何功能用到 AI 前，先检查 `ai_manager.is_configured('llm')`
4. **测试连接返回结构**：`data.ok` 布尔 + `data.message` 错误信息，前端按此渲染
5. **Embedding 模型名字段**：在 embedding_config 里是 `model_name`（不是 `embedding_model`，那只是 base.py 内部属性名）
6. **Claude 无 Embedding**：claude/deepseek 下拉在设置页 Embedding 栏不会出现
7. **运行前先激活 venv**：`source venv/Scripts/activate`（Git Bash）或 `venv\Scripts\activate`（CMD）
8. **测试 API**：`curl http://127.0.0.1:8888/api/xxx`（先 `python main.py` 起服务）
9. **git 仓库**：已关联 GitHub `EZ-lg/EduAgentHub.git`，每阶段完成后 commit + push（P2 等用户验收后再推）
10. **P9 试打包**：P2 的 Provider 用到了 openai/anthropic SDK，打包时 `--collect-all` 这两个库；`--add-data` 记得包含 `backend/ai/prompts` 目录
