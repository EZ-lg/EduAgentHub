## 一、项目概述

2.0 在 1.0（AI 对话式采集 + 按学科管理，单人单科助学）基础上，**把"个体助学"升级为"机构教务运营"**：

```
1.0：学生 ──学科──> 报告/规划/成绩/日志        （以"人"为单位，一对一助学）
2.0：学生 ──报班──> 班级 ──排课──> 课表        （以"课"为单位，一对多运营）
     + 全局总览把 学生信息/班级/规划 串成一张图
     + 全部设计可迁移到服务器部署为网站
```

一句话：**1.0 解决"单个学生怎么教"，2.0 解决"整个机构怎么排、怎么管、怎么一眼看清"。**

### 五大需求

| 编号 | 需求 | 落地 |
|------|------|------|
| G1 | 部署双轨（exe ↔ 服务器） | ✅ P1 可迁移性 + deploy/ + 双轨验证 |
| G2 | 班级管理（一对一 + 一对多小班） | ✅ P2 教室/班级/班级学生 |
| G3 | 智能排课（零冲突 + 教务确认） | ✅ P3 确定性约束求解 + AI 点评 |
| G4 | 全局总览（一个界面总览 + 钻取） | ✅ P5 工作台总览 + 待办 + 学生卡片流 |
| G5 | 学生界面（先看总体再细分） | ✅ P5 学生总览 + 学科卡 + 班级区 |

### 双轨部署形态（G1，架构级约束）

- **exe 形态**：`dist/TutoringAgent.exe`（windowed 无黑窗），数据隔离在 exe 同级 `data/`
- **服务器形态**：`uvicorn backend.app:app --host 0.0.0.0`，前端纯静态 + 后端 FastAPI 均可服务器托管（deploy/ 提供 Dockerfile + nginx.conf + deploy.md）
- **同一套代码**，两种形态功能完全一致（P6c 已演练，本轮打包后再次验证）

### 2.2 数据模型（16 张表）

```
1.0（12 张）：students / subjects / ai_conversations / reports / scores / course_plans
               / communication_logs / teachers / knowledge_docs / qa_history / settings / activity_logs
2.0（4 张新增）：
  classrooms      教室：name/capacity/location/status
  classes         班级：name/subject_id/subject_name/teacher_id/classroom_id
                   /class_type(1v1|1vN)/term_type(semester|summer_winter)
                   /total_lessons/daily_start/daily_end/weekly_frequency
                   /duration_minutes/start_date/end_date/status/notes
  class_students  班级学生：class_id/student_id/subject_id(可空)/enroll_date，唯一(class_id,student_id)
  class_schedules 课次：class_id/weekday/start_time/end_time/classroom_id/teacher_id/status(draft|active|archived)
```

**双维度心智（2.0 核心）**：
- **学习维度**（1.0 `subjects`）：学生"学什么"，报告/规划/成绩/日志挂这里，**不迁移**
- **上课维度**（2.0 `classes`）：机构"怎么上课"，绑定教师/教室/学生/排课
- 铁律：报告/规划/成绩/日志仍挂 `subjects`，不因班级引入而迁移

## 三、关键决策与踩坑（摘要，详见交接文档 §三/§五）

| 决策点 | 结论 |
|--------|------|
| 智能排课 | **确定性约束算法 + AI 点评**（LLM 不做求解，保证零冲突可复现） |
| 班级类型 | 学期班 = 每周固定 N 次循环；寒暑假班 = 每天固定 1 节、周日休息、总天数 N |
| 续课 | 同时段续课优先，续课撞占用 → 报冲突不落库（事务回滚） |
| 归节次标准 | 10:30 前结束=上午一、10:30 后开始=上午二、16:00 前结束=下午三、16:00 后开始=下午四；时间可自定义 |
| 学蝉功能 | 签到/消课/统计/财务本次不纳入 |
| 一对多小班 | 也走个性化（各自 AI 采集+报告，上课跟班级课表） |

**高频踩坑（交接文档已详录，改代码前必读）**：
`autoflush=False` 需显式 `db.flush()` / API 400 返回 `{"detail":...}` 无 success 键 / 改前端必递增 APP_VERSION + 同步 `?v=` / 页面 onclick 函数必须 `Object.assign` 导出 / 改排课只动 `scheduler.py` / 回归测试用 `EDU_DATA_DIR` 临时库隔离。
